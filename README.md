# Spatial Agent Interaction Research

> 面向长时空间任务的智能体交互机制研究——态势感知与动态干预

本仓库用于管理论文研究全过程。**正式论文正文与研究过程材料分开管理**：论文正文放在 `paper/`，文献、研究框架、实验记录等使用 Markdown 等便于版本管理的格式。

## 当前研究问题

随着 Agent 从一次性问答转向长时运行、多阶段规划、工具调用以及可中断执行，用户面临的关键问题不再只是“能否获得正确结果”，而是：

> 用户能否在 Agent 执行过程中持续理解其任务目标、当前状态、行为依据和后续趋势，并在必要时进行有效干预？

当前归纳为两个核心目标：

1. **建立正确的用户态势认知**：让用户知道 Agent 当前在做什么、进行到哪里、重要变化是什么、接下来可能发生什么。
2. **支持有效的人机协同控制**：让用户能在适当时机确认、纠偏、调整或中止 Agent 行为。

## 仓库结构

```text
paper/
  thesis.docx              # 正式论文正文（后续放入）
  README.md                # 正文管理说明

research/
  research-question.md     # 研究问题、目标、边界
  framework.md             # 态势感知与动态干预研究框架
  methodology.md           # 研究方法与验证设计

literature/
  papers/                   # 阅读/引用的外部论文 PDF
  notes/                    # 文献阅读笔记

experiments/
  protocols/                # 专家评审、用户实验、对照实验方案
  results/                  # 实验结果与分析

prototype/                  # 交互原型、实现说明
assets/
  figures/                  # 论文图表、模型图、实验截图
references/
  references.bib            # 参考文献数据库
data/                       # 非敏感研究数据
```

### `paper/` 与 `literature/papers/` 的区别

- `paper/`：**我们自己正在撰写的论文**。
- `literature/papers/`：**别人已经发表、用于阅读和引用的论文**。

因此正式论文主文件只保留一处：`paper/thesis.docx`。

## 研究原则

- 先明确研究问题，再选择实现技术。
- 区分“系统工程能力”和“论文研究贡献”。
- 每项交互机制都应对应明确的用户问题。
- 论文结论尽量由文献、实验、专家评审或其他可复核证据支撑。
