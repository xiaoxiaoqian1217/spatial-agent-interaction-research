# Spatial Agent Interaction Research

> 面向长时空间任务的智能体交互机制研究——态势感知与动态干预

本仓库用于沉淀论文研究过程，包括研究问题、理论框架、文献笔记、实验设计、原型实现、数据与论文写作材料。

## 研究问题

随着 Agent 从一次性问答转向长时运行、多阶段规划、工具调用以及可中断执行，用户面临的关键问题不再只是“能否获得正确结果”，而是：

> 用户能否在 Agent 执行过程中持续理解其任务目标、当前状态、行为依据和后续趋势，并在必要时进行有效干预？

论文暂将问题归纳为两个核心目标：

1. **建立正确的用户态势认知**：让用户知道 Agent 当前在做什么、为什么这样做、进行到哪里、接下来可能发生什么。
2. **支持有效的人机协同控制**：让用户能在适当时机确认、纠偏、调整或中止 Agent 行为。

## 初步研究框架

```text
Agent 长时空间任务中的人机协作
│
├─ 1. 用户态势认知
│  ├─ 注意力选择：用户需要知道什么？
│  ├─ 状态可理解性：Agent 现在在做什么？
│  ├─ 连续性：当前事件与前后过程如何关联？
│  └─ 可预期性：接下来会发生什么？
│
└─ 2. 人机协同控制
   └─ 可介入性：用户何时、以什么方式介入？
```

该框架后续将通过文献研究、交互原型、专家评审与对照实验逐步修正，而不是预设为最终结论。

## 原则

- 先研究问题，后技术实现。
- 区分“系统工程能力”和“论文研究贡献”。
- 所有交互机制都必须能够映射到明确的用户问题。
- 所有论文结论都尽量通过可复现的实验、评审或证据支撑。
