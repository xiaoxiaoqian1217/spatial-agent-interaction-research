# Prototype

本目录用于保存论文实验原型及其实现说明。

原则：原型只服务于研究问题验证，不追求完整产品化。

建议记录：

- 原型目标；
- 对应研究维度；
- 场景与任务流程；
- 关键交互机制；
- 技术实现；
- 与实验条件的对应关系。

## 当前最小实现约定（2026-09-16）

围绕既有“异常后的自主接替”“新增区域后的主动调整”案例，组合上下文模型、规则与状态机，不使用 LLM。当前仅确定设计，尚未实现或验证。

- 共用情境输入、对象标识、地图组件、业务操作和权限约束；规则与状态机可用于多个环节，不额外拆分 Agent。
- 提供 B0 固定组织、B1 直接情境规则映射、P 显式 Need 映射三种条件；先完成 B1/P 离线回放，再完成用于整体用户对照的 B0/P。
- 记录情境版本、命中规则、Need（仅P）、策略、用户操作、反馈和时间；保留未知及证据不足状态。
- 选区通过共享状态提供，结构化路线由前端规则绘制；需要浏览器执行并回传结果时才使用前端工具。
- 保护编辑/选区中的视野，提供定位提示、取消建议和恢复全局；不得由界面适配扩大后台执行权限。
